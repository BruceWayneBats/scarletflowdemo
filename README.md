# ScarletFlow — сайт продукта

Статический сайт на [Astro](https://astro.build): HTML и CSS, немного JavaScript только там, где он нужен (калькулятор, формы, вкладки). Публикуется на GitHub Pages автоматически при каждом push в `main`.

Сейчас: https://brucewaynebats.github.io/scarletflowdemo/

## Запуск у себя

```bash
npm ci
npm run dev        # http://localhost:4321/scarletflowdemo/
npm run verify     # сборка и проверки: типы, внешние ресурсы, вес страниц, контраст
npm run preview    # собранный сайт
npm run check:links  # битые ссылки (при запущенном preview)
```

## Как поменять текст

Подробное руководство для владельца: [docs/site-content-guide.md](docs/site-content-guide.md).

- Главная: `src/content/home.ts` — первый экран, шаги, вкладки, безопасность, цены, вопросы.
- Юридические данные и контакты: `src/content/legal.ts`. Всё со словом `TODO` заполнить до запуска.
- Отдельные страницы: `src/pages/*.astro`, текст прямо в разметке.
- Правила текстов: никаких абсолютных обещаний («0 ошибок», «100 %»), никаких выдуманных кейсов и цифр, деньги — только как оценка.

После правки: `npm run verify`, commit, push в `main` — через пару минут сайт обновится (вкладка Actions).

## Как добавить страницу

1. Создайте `src/pages/<адрес>.astro` по образцу `missed-calls.astro`: `Base` (заголовок, описание, путь) + `PageHero` + `Prose`.
2. Добавьте ссылку в `src/content/nav.ts` (подвал) — sitemap обновится сам.

## Настройки

`src/config.ts`:
- `apiBase` — адрес нашего бэкенда для форм и демо. Пустая строка: формы проверяют поля и показывают «демо-режим», ничего не отправляя.
- `casesEnabled` — раздел кейсов скрыт, пока нет реальных согласованных результатов.
- `consentVersion` — версия текста согласия, которую формы отправляют вместе с заявкой.

## Свой домен

1. В `astro.config.mjs`: `SITE = "https://<домен>"`, `BASE = "/"`; в `scripts/check-*.mjs` поправить `OWN` и `BASE`.
2. Создайте `public/CNAME` с одной строкой — доменом (пример в `docs/CNAME.example`).
3. У регистратора: для домена второго уровня — A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (и AAAA `2606:50c0:8000::153` … `8003::153`); для поддомена — CNAME на `brucewaynebats.github.io`.
4. В настройках репозитория → Pages: указать домен, дождаться сертификата, включить «Enforce HTTPS».

## Картинки

`public/og.png` (превью ссылки) и `public/apple-touch-icon.png` генерируются из `scripts/og.html` и `scripts/icon.html`: `scripts/make-images.sh` (нужен установленный Google Chrome). Знак и иллюстрации — SVG в `src/components/`.

## Что сюда нельзя

Репозиторий публичный: никаких токенов, паролей, ключей, персональных данных и внутренних документов. Сайт не подключает внешние шрифты, счётчики и скрипты: всё раздаётся с этого же хоста (проверка `scripts/check-external.mjs`).

Шрифты: Cormorant Garamond и Manrope, лицензия SIL Open Font License, пакеты `@fontsource`.
